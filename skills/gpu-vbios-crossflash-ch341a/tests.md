# Tests — manual checklist

1. **Image gate passes on a good ROM.** Download the ROM via any Step 1 source. Confirm `stat` reports 262144 bytes and `file WX9100_BIOS.rom` output contains `0x1002:0x6861` (accept any `file`-version wording, e.g. "PCI ISA ROM image (PCI device 0x1002:0x6861, ...)"). If `file` wording is ambiguous, `xxd WX9100_BIOS.rom | grep -i 6861` must hit. A deliberately truncated file (`head -c 100000 WX9100_BIOS.rom > bad.rom`) must FAIL the size check.
2. **Padding produces exactly 1 MiB.** After Step 3, `stat -c%s WX9100_171219_padded.rom` (or `-f%z` on macOS) returns 1048576, and `cmp -n 262144 WX9100_BIOS.rom WX9100_171219_padded.rom` reports no difference (original image intact at the start of the padded file).
3. **Chip name is discovered, not assumed.** `flashrom -p ch341a_spi` (no `-c`) prints a "Found ... flash chip" line; the operator records that string as `<CHIP>` and every subsequent command uses it. Reviewer confirms no command in the executed session hardcodes `M25P80` unless detection actually reported it.
4. **Backup self-consistency gate works.** Two consecutive reads produce identical `sha1sum` output for `mi25_backup1.rom` and `mi25_backup2.rom`. Reviewer confirms the check compares the two files to each other and that no step compares against an external/reference hash. (Simulate a flaky clip: a deliberately corrupted second read must produce differing hashes and halt the procedure.)
5. **Flash verification string observed.** Step 7 output contains the literal `Verifying flash... VERIFIED.` — anything else (error, no verify line) means failure.
6. **Post-flash identity.** With the card reinstalled and 6-pin power connected, `lspci -nn | grep Vega` shows `1002:6861`; `rocm-smi` lists the GPU. Revert path exists: rewriting `mi25_backup1.rom` with the same flashrom invocation restores the original double-read-verified backup.
